# نظام حسابات محل الذهب — الخطة

نظام عربي بالكامل (RTL) لتسجيل الوارد والمنصرف من الذهب والفلوس مع كل تاجر، ومعرفة كل لحظة: أنا ليّ كام وعليّ كام — دهب (بعيار 21) وفلوس.

## 1. التجار

- إنشاء تاجر: الاسم، التليفون، النوع (تاجر مشغولات / تاجر خام)، ملاحظات.
- صفحة لكل تاجر فيها: رصيد الدهب (جرام عيار 21) + رصيد الفلوس، تفصيل الأرصدة بالعيارات الأصلية، وكشف حساب بكل الحركات.
- إشارة واضحة: **ليّ** (أخضر) / **عليّ** (أحمر).

## 2. أنواع الحركات

### تاجر مشغولات
- **وارد (شغل داخل):** اختيار العيار (18 / 21) ثم الصنف، الوزن بالجرام (رقمين عشريين)، المصنعية للجرام → النظام يحسب الإجمالي تلقائياً (وزن × مصنعية).
  - الأصناف: مشغولات عيار 21، مشغولات عيار 18 (إجمالي)، خواتم، غوايش، حلقان، دبل، أساور، أنسيالات، سلاسل، تعاليق، أطقم، كف، مشابك.
  - **الغوايش فقط** فيها خانة (عدد) إضافية.
  - الأثر: دهب عليّ + فلوس (مصنعية) عليّ.
- **تسديد (منصرف):** طريقة السداد:
  - نقدية (فلوس) → ينزل من الفلوس اللي عليّ.
  - كسر 21 / كسر 18 → يتحول لـ 21 وينزل من الدهب اللي عليّ.
  - سبيكة كاشباك → وزن + قيمة الكاشباك للجرام؛ الدهب ينزل من عليّ، والكاشباك يُسجل فلوس **ليّ**.
  - سبيكة عيار مختلف → أكتب العيار (مثال 830) + وزن؛ تحويل لـ 21 + 8 جنيه للجرام تُسجل فلوس ليّ.
  - بندقي (عيار 991) → نفس المعالجة + 8 جنيه للجرام.
  - أوجر إلى دهب → أكتب مبلغ الفلوس + سعر الجرام؛ الفلوس تنزل من عليّ ويزيد دهب عليّ.
  - تحويل من حساب تاجر آخر → ينزل من حسابي عند تاجر ويضاف عند الآخر (حركة مزدوجة).

### تاجر خام
- **شراء دهب:** أصناف ثابتة الأوزان — عيار 24: ربع، نص، جرام، 2.5، 5، 10، 20، 50، 100، أو وزن حر. عيار 21: ربع، نص، جنيه. + بندقي. مع خانة مصنعية.
  - الأثر: دهب ليّ + فلوس عليّ.
- **بيع دهب:** العكس — فلوس ليّ + دهب عليّ (أو للتاجر).
- **سداد:** بندقي، سبيكة عيار مختلف، سبيكة كاشباك، نقدية.
- بدون كسر (لا علاقة له بالكسر).

## 3. المعادلات (نقاء العيارات)

| العيار | النقاء |
|---|---|
| 24 | 1000 |
| 21 | 875 |
| 18 | 750 |
| بندقي | 991 |
| عيار حر | يُكتب |

التحويل: `وزن × نقاء العيار ÷ 875 = ما يعادله عيار 21`
كل رصيد يُخزَّن بالوزن والعيار الأصلي، ويُعرض محوَّل لعيار 21 مع تفصيل بالعيارات.

## 4. سعر الذهب

صفحة/خانة لسعر جرام عيار 21 اليومي — يُدخل مرة ويُستخدم تلقائياً في أي حركة تحتاج تحويل فلوس↔دهب، مع إمكانية تعديل السعر داخل الحركة نفسها.

## 5. الملخص العام

صفحة رئيسية تعرض:
- إجمالي الدهب اللي عليّ / ليّ (جرام 21) من كل التجار (خام + مشغولات).
- إجمالي النقدية اللي عليّ / ليّ.
- قائمة التجار مرتبة بالرصيد، بحث سريع، وأزرار سريعة: حركة جديدة / تسديد.

## 6. السرعة وسهولة الاستخدام

- تصميم موبايل-أول: أزرار كبيرة، اختيار الصنف والعيار بأزرار (chips) لا قوائم منسدلة، لوحة أرقام مناسبة للموبايل.
- نموذج الحركة في شاشة واحدة، والحساب يظهر لحظياً قبل الحفظ.
- إدخال أكثر من بند في نفس الوارد (شروة واحدة) بضغطة إضافة.
- يعمل بنفس الكفاءة على اللابتوب (شاشة أوسع بجداول).

## 7. المستخدمون والتتبع (Audit)

- تسجيل دخول بالبريد وكلمة السر.
- دور **مدير**: الفرق الوحيد أنه يقدر يضيف/يوقف مستخدمين.
- كل المستخدمين يشوفون نفس البيانات ويسجلون الحركات.
- **سجل تتبع كامل**: كل إضافة/تعديل/حذف تُسجل (من، إمتى، إيه اتغير) في صفحة سجل قابلة للتصفية.

## التفاصيل التقنية

**قاعدة البيانات (Supabase):**
- `profiles` — بيانات المستخدم (الاسم) مرتبطة بـ auth.users، تُنشأ بـ trigger.
- `user_roles` + enum `app_role ('admin','user')` + دالة `has_role` (security definer) — الأدوار في جدول منفصل لا في profiles.
- `merchants` — الاسم، التليفون، النوع (`merchant_type`: `jewelry` | `raw`)، ملاحظات.
- `item_categories` — أصناف ثابتة (seed) مع علم `tracks_count` للغوايش، وعلم النوع المسموح.
- `gold_prices` — تاريخ + سعر جرام 21 (سعر يومي، قابل للتعديل).
- `transactions` — التاجر، النوع (`inbound` | `settlement` | `purchase` | `sale` | `transfer`)، طريقة السداد، التاريخ، سعر الذهب المستخدم، ملاحظات، `created_by`.
- `transaction_lines` — الصنف، العيار (`karat_purity` numeric)، الوزن (numeric 12,2)، العدد (nullable)، المصنعية/الكاشباك للجرام، القيم المحسوبة: `weight_21` و `cash_amount`، واتجاه الأثر (`gold_direction`, `cash_direction`).
- `audit_log` — الجدول، معرف السجل، العملية، البيانات قبل/بعد (jsonb)، المستخدم، الوقت — يُملأ بـ triggers على كل الجداول التشغيلية.
- View/دالة `merchant_balances` لحساب صافي الدهب (جرام 21) والنقدية لكل تاجر، وتفصيل بالعيارات.
- RLS: كل الجداول مفعّلة؛ القراءة والكتابة للمستخدمين المصادَقين (`authenticated`)؛ إدارة المستخدمين والأدوار للمدير فقط عبر `has_role`. مع GRANT لكل جدول.

**الواجهة:**
- `dir="rtl"` + `lang="ar"` على مستوى الجذر، وخط عربي واضح (Cairo / IBM Plex Sans Arabic).
- المسارات: `/auth` عامة، والباقي تحت `_authenticated`: `/dashboard`، `/merchants`، `/merchants/$id`، `/transactions/new`، `/prices`، `/audit`، `/users` (للمدير).
- منطق التحويل والحسابات في وحدة واحدة `src/lib/gold-math.ts` مستخدمة في الواجهة والسيرفر لتفادي اختلاف النتائج.
- القراءة/الكتابة عبر `createServerFn` مع `requireSupabaseAuth` و TanStack Query.

## ترتيب التنفيذ

1. الهجرة (Migration): الجداول، الأدوار، RLS، triggers التتبع، وseed الأصناف والعيارات.
2. المصادقة + الجذر العربي RTL + الحماية.
3. التجار: القائمة + إنشاء + صفحة التاجر.
4. سعر الذهب + وحدة الحسابات.
5. شاشة الحركة (وارد / تسديد / شراء / بيع / تحويل).
6. لوحة الملخص العام.
7. سجل التتبع + إدارة المستخدمين للمدير.
